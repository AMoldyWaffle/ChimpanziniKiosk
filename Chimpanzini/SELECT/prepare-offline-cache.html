Prepare Offline Cache

Run this once (or again any time you add/replace files in the data folder). It copies everything the emulator needs into a data-cache folder next to it, so that index.html can load it directly from disk with no server of any kind.

Select the project's root folder - the one that directly contains index.html and the data folder (this is the same folder you'd normally pick "SELECT" inside of - one level up from that).
